PONDOK PESANTREN AL-HUSNA — WEBSITE REDESIGN

Isi folder:
- index.html : website versi desain modern
- logo.png   : logo resmi pesantren

Cara upload ke GitHub Pages:
1. Ekstrak ZIP ini.
2. Buka repositori GitHub: Pondok-Pesantren-Al-Husna-Marindal.
3. Upload/ganti index.html dan logo.png di folder utama (root).
4. Commit changes.
5. Tunggu GitHub Pages selesai memperbarui website.

Catatan penting:
- Website ini masih menggunakan localStorage browser untuk menyimpan data. Data pendaftaran/admin tidak otomatis terkirim ke server atau tersinkron antarperangkat.
- Login demo admin masih tertanam di JavaScript publik: username admin, password alhusna123. Ini bukan sistem autentikasi aman untuk data nyata. Jangan gunakan untuk menyimpan data santri sensitif sebelum dipindahkan ke backend dengan autentikasi dan database yang aman.
- Gambar hero memakai URL Unsplash eksternal sehingga memerlukan koneksi internet.
