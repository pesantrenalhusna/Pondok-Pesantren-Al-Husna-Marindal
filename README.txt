PONDOK PESANTREN AL-HUSNA MARINDAL — PORTAL WEBSITE

Pembaruan latar belakang menggunakan foto asli yang diberikan: 
- suasana-al-husna.webp: foto lingkungan/gedung pesantren untuk hero beranda.
- kegiatan-santri-al-husna.webp: foto kegiatan santri untuk bagian visual beranda.

Cara unggah ke GitHub Pages:
1. Ekstrak ZIP ini.
2. Unggah seluruh isi folder (index.html, logo.png, dan kedua foto .webp) ke direktori publik repository.
3. Pastikan nama dan lokasi kedua file foto tidak diubah agar latar tampil dengan benar.
4. Commit/push perubahan lalu tunggu GitHub Pages memperbarui website.
